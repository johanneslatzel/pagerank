Zero-dependency weighted PageRank for TypeScript.

> **Disclaimer**: This package was written entirely by AI. Use at your own risk.

## Why does this package exist?

[llm-chat-memory](https://github.com/johanneslatzel/llm-chat-memory) required a weighted PageRank implementation with minimal dependencies, ESM, and TypeScript types. At that time existing packages were either CommonJS-only, untyped, or pulled in heavy dependencies for a single algorithm.

## Features

- weighted Pagerank implementation with uniform teleportation
- minimal implementation without dependencies
- typed and ESM-native

## Installation
